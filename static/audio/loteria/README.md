# Audio de las cartas de lotería

La voz del gritón funciona sin archivos de música. Para usar grabaciones propias o autorizadas, coloca aquí los archivos MP3: `venado.mp3`, `botella.mp3`, `diablito.mp3`, `camaron.mp3`, `pescado.mp3` o `cazo.mp3`.

El servidor anuncia solo los archivos que existan. Al salir la carta reproduce un fragmento limitado por la velocidad de la ronda y después dice su frase. Cambiar de carta, terminar, silenciar, ocultar la pestaña o salir de la sala detiene el audio anterior. Si el navegador impide reproducir el MP3, usa la voz del gritón.

No se incluye ninguna grabación de El Venao ni de otras canciones. El actualizador no descarga, reemplaza ni elimina estos MP3. Recarga la web después de añadir un archivo; no es necesario editar el código.
